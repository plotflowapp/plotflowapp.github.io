What It Checks

Catch common plotting problems before they reach the PDF.

Pre-Plot Check groups findings by severity and shows which layout each issue belongs to.

↗

External references

Find xrefs that are missing, unloaded or using absolute paths that may break when a drawing moves to another computer.

▧

Images and PDF underlays

Spot referenced images and PDF underlays that AutoCAD can no longer locate.

T

Missing fonts

Find text styles pointing to fonts that are not installed and may be substituted in the PDF.

□

Layouts without viewports

Identify layouts that have a sheet frame but no viewport showing the drawing.

Aa

Title-block leftovers

Flag common placeholders such as TBD, TBC, TODO, XXX and ???, plus empty sheet numbers or sheet titles in supported block attributes.

#

Duplicate sheet numbers

Find sheets that use the same sheet number, helping catch a common issue before publishing.

Compatibility & FAQ

Good to know before installing.

Which AutoCAD versions are supported?

Pre-Plot Check is built for full AutoCAD 2024, 2025, 2026 and 2027 on 64-bit Windows. AutoCAD LT does not support this type of plugin. AutoCAD-based products such as Architecture and Civil 3D have not yet been tested.

Does it change my drawing?

No. It reads the drawing and reports findings. It does not modify the DWG or send your drawing data anywhere.

Can it find every title-block sheet number?

Title-block checks look for block attributes with common names such as SHEET_NUMBER, SHEETNO or DWG_NO. If your sheet number is plain text rather than an attribute, that specific check cannot detect it.

How do I install it?

Close AutoCAD, run the installer (administrator rights are not required), then start AutoCAD. When prompted to load Pre-Plot Check, choose “Always Load”. The prompt appears because the plugin is not digitally signed.

How do I uninstall it?

Open Windows Settings → Apps and uninstall “Pre-Plot Check for AutoCAD”.
