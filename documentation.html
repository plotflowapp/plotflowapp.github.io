Installation

Toritex is installed using the Toritex installer. After installation, the plugin integrates with AutoCAD and does not require a manual NETLOAD step for normal use.

  1. Close AutoCAD before running the installer.
  2. Run the Toritex installer and follow the installation steps.
  3. Start AutoCAD.
  4. Open a drawing and locate Toritex in the AutoCAD interface.
Supported versions: AutoCAD 2023, 2024, 2025, 2026 and 2027, 64-bit.

First run

Toritex works with layouts in the drawing that is currently open in AutoCAD. Start Toritex from the AutoCAD interface or use the TORITEX command.

The workflow is simple: select the layouts you want to publish, choose the PDF output mode, configure the output and publish.

Select layouts

The layout list lets you choose exactly which layouts should be included.

  • All — select all available layouts.
  • None — clear the current selection.
  • Invert — reverse the current selection.
  • Search — filter the layout list.
Tip: Only selected layouts are sent to the publishing operation.

PDF output

Toritex supports two output modes.

ModeResult
Single PDFSelected layouts are published as one multi-page PDF.
Separate PDFsEach selected layout is published as its own PDF file.

Output folder

Choose the destination folder for generated PDF files. Toritex remembers the last used folder.

Filename templates

When publishing separate PDFs, Toritex can build filenames from templates. Use the live preview to check the result.

FieldMeaning
{Drawing}Current drawing name.
{Layout}Layout name.
{Date}Current date.
{Time}Current time.
{Index}Sequential export index.

Invalid filename characters are sanitized automatically.

Presets

Save frequently used export settings as presets instead of configuring the same options every time. Presets are useful for repeated projects and workflows.

Troubleshooting

Toritex does not appear in AutoCAD

  • Restart AutoCAD after installation.
  • Confirm that you installed the correct Toritex release.
  • Try the TORITEX command.

A PDF was not created

  • Confirm that the output folder is accessible.
  • Check that selected layouts have valid plot settings.
  • Make sure the configured AutoCAD plotter is available.
  • Review the Toritex result/summary after publishing.

One layout fails during a batch

A failure on one layout does not automatically stop the remaining export operation. Review the final result summary to identify the affected layout.

Limitations

Toritex is focused on publishing layouts from the drawing currently open in AutoCAD.

  • Toritex does not batch-process multiple DWG files in one operation.
  • Toritex does not add stamps, watermarks or logo overlays to PDFs.
  • The publishing workflow uses AutoCAD's available plotting configuration.
Need help? Contact Toritex support with your AutoCAD version and a description of the problem.
