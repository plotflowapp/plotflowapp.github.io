THE PROBLEM

AI geometry can be useful — but its UVs often aren't.

AI-generated models from tools such as Hunyuan or Tripo can arrive with a mosaic-like UV layout and a difficult-to-work-with mesh. After retopology and a new UV unwrap, the original texture no longer fits the new model.

THE WORKFLOW

Let 3ds Max do the baking work.

ai2tex automates the built-in 3ds Max Projection + Render To Texture workflow. It sets up the projection, handles the temporary scene changes, bakes the color and cleans up afterwards.

  • Pick the original textured Source.
  • Pick the retopologized Target.
  • Use the Target's existing UV channel.
  • Adjust Ray offset if necessary.
  • Press Bake.

FEATURES

Everything around the bake is handled for you.

The tool is intentionally focused: one Source, one Target, one Diffuse / Base Color bake at a time.

01

Source / Target picking

Select the two meshes directly in 3ds Max. Clear resets the selection.

02

Automatic Ray offset

ai2tex calculates a starting value from the object's size. Fine-tune it when needed.

03

UV check

The selected Target UV channel is checked and the script can report where an existing unwrap is found.

04

Clean scene handling

Temporary Projection, material and renderer changes are restored after the bake.

WHAT IS TRANSFERRED

Color, not the whole material stack.

The current version is deliberately limited to Diffuse / Base Color. Geometry and UVs are not changed.

  • Diffuse / Base Color
  • Standard Material diffuse + bitmap
  • Physical Material Base Color + bitmap
  • Multi/Sub-Object using supported Standard / Physical sub-materials
NOT CURRENTLY TRANSFERRED

The Target keeps its existing geometry and UV layout. A new Standard Material can be assigned to the Target after baking.

OUTPUT

Predictable output, with no silent overwrites.

PNG / JPG / TGA

PNG is the default. JPG is baked at quality 100 for the operation. TGA is also available.

512 → 8192

Choose a square output texture size from 512, 1024, 2048, 4096 or 8192.

_TexBake

The output is saved beside the first found Source texture when possible, using the _TexBake suffix.

No overwriting

Existing files are never overwritten. Repeated bakes receive _1, _2, and so on.
