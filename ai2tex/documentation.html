Install and use ai2tex.

Installation and usage instructions for the current release.

Installation

Place the supplied script/package according to the instructions included with the release. The exact installation method and supported 3ds Max versions should be documented here before publishing the final download.


Basic workflow

1. Import the original textured AI-generated model.
2. Create the optimized / retopologized target.
3. Prepare the target UV layout.
4. Select the source and target as required by the current release.
5. Run ai2tex and create the transferred texture.
6. Continue working with the optimized asset.


Current limitations

The current version focuses on Diffuse / Base Color texture information. Normal, Roughness, Metallic, Opacity, Emission and AO maps are not currently transferred.
